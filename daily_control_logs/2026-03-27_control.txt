2. Doctor Demo Page — Bug Fix #1: Patient Auto-Select from URL
   - Problem: URL has ?fileid=Input_Keystrokes...&doctorid=Interviewer: but page shows
     patient list without auto-selecting the matching patient
   - Root cause: PhysicianReportsModifiedV41Timothy.tsx had no logic to match URL fileId
     against loaded patient list
   - Fix (after line ~3591): Added useEffect + useRef for one-time auto-select:
     ```typescript
     const autoSelectDone = React.useRef(false);
     useEffect(() => {
       if (patients.length > 0 && selectedFile && !autoSelectDone.current) {
         const match = patients.find((p) => p.fileName === selectedFile);
         if (match) {
           setSelectedPatient(match);
           setCurrentView("grid");
           autoSelectDone.current = true;
         }
       }
     }, [patients, selectedFile]);
     ```
   - useRef prevents re-triggering when user clicks "Return to Dashboard"
     (which calls setSelectedPatient(null))

5. Consultation Scoring — .pred_1 Misuse Replacement
   - Problem: .pred_1 (NLP sentence relevance probability, 0.0-1.0) was being displayed
     as consultation quality score (0-5 integer scale) in Doctor Demo page
   - This is semantically wrong: .pred_1 measures "how relevant is this sentence to the topic",
     NOT "how well did the doctor communicate about this topic"
   - Real consultation scores will come from Guillermo's Step 8 (AI selector)
   - Temporary fix — deterministic pseudo-random placeholder (1-5):
     ```typescript
     const getPlaceholderScore = (fileName: string, topicName: string): number => {
       let hash = 0;
       const seed = `${fileName}::${topicName}`;
       for (let i = 0; i < seed.length; i++) {
         hash = ((hash << 5) - hash + seed.charCodeAt(i)) | 0;
       }
       return (Math.abs(hash) % 5) + 1;
     };
     ```
   - Deterministic: same file+topic always produces same score (no flicker on re-render)
   - Applied to 5 locations in PhysicianReportsModifiedV41Timothy.tsx:
     a. getLastSentenceScore() — per-topic score display
     b. overallScore useMemo — average of 5 topic placeholder scores
     c. Patient list rendering — overallScore per patient row
     d. ConsultationScoring component — highlightPosition, title, suggestions props
     e. Topic trajectory chart — score per consultation event
