======================================

용어 정의: 이 문서에서 "NLP"는 Michael의 r01-nlp-classifiers Docker 컨테이너를
의미합니다 — R 4.5.1 + vetiver + plumber 기반 ranger (Random Forest) 이진 분류기 5개.
모델: cp (암 예후), le (기대 수명), ed (발기 부전), inc (요실금), ius (자극성 배뇨 증상).
LLM이나 일반 NLP 라이브러리를 지칭하는 것이 아닙니다.

2026년 2월 10일:

1. NLP API 프로덕션 레디 통합 (app/Backend/)
   - redis_client.py 생성: Redis 연결 관리 모듈, 우아한 성능 저하(graceful degradation) 지원 (init/close/get 라이프사이클)
   - nlp_service.py 생성: NLP API 클라이언트 — httpx 커넥션 풀링, 지수 백오프 재시도 (3회), Redis 캐싱 (1시간 TTL), predict_single/predict_batch/predict_all_models 함수
   - routes_nlp.py 생성: 6개 NLP 프록시 엔드포인트 (/api/nlp/health, /predict, /predict/batch, /predict/by-class, /predict/all, /models) — Pydantic 유효성 검증 및 API 키 인증
   - main.py 수정: Redis/NLP 시작/종료 라이프사이클 이벤트 추가, 상태 확인 엔드포인트 확장 (DB+Redis+NLP), score-sentence 하드코딩 5.0을 실제 NLP 모델 호출로 교체 (실패 시 폴백)
   - docker-compose.yml 수정: NLP 서비스 3개 복제본(replicas)으로 확장, 인스턴스당 2G 메모리 제한 추가, container_name 및 외부 포트 제거 (내부 네트워크 전용), start_period 90초로 증가
   - api_call_test.rest 수정: 13개 NLP 프록시 테스트 케이스 추가 (상태 확인, 모델 목록, 단일 예측 x5, by-class x2, 배치, 전체 모델, 캐시 검증, 오류 테스트)
